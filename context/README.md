## Quick Start

If you're new to the project, read these in order:
1. Project Overview
2. Architecture & Tech Stack
3. Data Models & Types
4. State Management

Then reference other documents as needed for specific features.

## Updating These Documents

These documents should be kept up-to-date as the codebase evolves. When making significant changes:
- Update the relevant context document
- Add new documents if introducing new major concepts
- Keep documents focused and bite-sized
