# Health Report Export

## Overview

The app supports exporting comprehensive health reports for each pet using React Native's built-in Share API. Users can share professional reports that include:
- Pet information (name, breed, age, personality)
- Month-to-date task completion statistics
- Daily, weekly, and monthly task tracking
- Completion rates and averages
- Professional text formatting suitable for veterinary consultations

## Installation

**No additional packages required!** This feature uses React Native's built-in `Share` API.

## Implementation Details

### Files Created/Modified

1. **`src/services/PdfReportService.ts`** (NEW)
   - Generates formatted text reports
   - Uses React Native's Share API to share reports
   - Formats data for professional report layout

2. **`src/screens/PetProfilesScreen.tsx`** (MODIFIED)
   - Added Share Report button functionality
   - Integrated with PdfReportService
   - Added loading states and error handling

3. **`src/services/TaskReminderService.ts`** (MODIFIED)
   - Added `completionHistory` array to track all task completions
   - Added statistical analysis methods:
     - `getCompletionsInRange()` - Get completions in date range
     - `getMonthlyCompletionCount()` - Count monthly completions
     - `getCompletionRate()` - Calculate completion percentage
     - `getAverageCompletionsPerWeek()` - Calculate weekly averages

## Usage

### For Users

1. Navigate to **Pet Profiles** screen
2. Tap on a pet card to expand it
3. Click **"More Info"** to see detailed statistics
4. Click **"Share Report"** button
5. Choose how to share (Messages, Email, Notes, etc.)

### For Developers

```typescript
import PdfReportService from '../services/PdfReportService';

// Generate and share report
await PdfReportService.generateHealthReport({
  pet: petObject,
  userTasks: userTasksObject,
  taskReminderState: taskReminderStateObject,
  reportDate: new Date(),
});
```

## Sharing Options

The report can be shared through:
- **Messages** - Text to vet or family
- **Email** - Send to veterinarian
- **Notes** - Save for personal records
- **Files** - Export to cloud storage
- **Clipboard** - Copy for pasting elsewhere
- **Any app** - Any app that accepts text sharing

## Data Statistics

### Daily Tasks
- Shows: `11/12 days (92%)`
- Meaning: Completed 11 out of 12 days this month (92% completion rate)

### Weekly Tasks
- Shows: `2/2 weeks (1.0/week avg)`
- Meaning: Completed 2 times out of 2 expected weeks (averaging 1.0 completion per week)

### Monthly Tasks
- Shows: `✅ Completed (5 days ago)` or `❌ Not completed`
- Meaning: Clear status of whether the monthly task was done

## Advantages of Share API

1. **No Dependencies** - Uses built-in React Native functionality
2. **Universal** - Works on all platforms without native linking
3. **Flexible** - Users choose their preferred sharing method
4. **Reliable** - No native module compatibility issues
5. **Fast** - Instant sharing, no file generation delay
6. **Simple** - Easier to maintain and debug

## Error Handling

## Troubleshooting

### Share Menu Not Appearing
- Ensure device has sharing capability enabled
- Check app permissions

### Text Not Formatting Correctly
- Some apps may not preserve line breaks
- Recommend using Notes or Email for best formatting
