# Internationalization (i18n)

The app supports multiple languages using react-i18next and expo-localization.

## Supported Languages

- **English (en)**: Default language
- **Chinese (zh)**: Simplified Chinese
- **Japanese (ja)**: Japanese

## Setup

**Location**: `src/utils/i18n.ts`

Initializes i18next with:
- Language detection from device locale
- Translation files from `src/locales/`
- Fallback to English if translation missing

## Translation Files

**Location**: `src/locales/`

- `en.json` - English translations
- `zh.json` - Chinese translations
- `ja.json` - Japanese translations

## Usage

### In Components

```typescript
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation();
  
  return <Text>{t('welcome.message')}</Text>;
}
```

### Translation Keys

Keys follow a hierarchical structure:
```json
{
  "welcome": {
    "title": "Welcome",
    "message": "Welcome to CAT-able!"
  }
}
```

Access with: `t('welcome.title')`

## Language Selection

Users can change language in SettingsScreen. The preference is stored in the User model and persisted.

## Best Practices

1. **Always use translation keys** instead of hardcoded text
2. **Use descriptive keys** that indicate context
3. **Keep translations updated** when adding new features
4. **Test with different languages** to ensure UI doesn't break
